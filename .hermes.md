# Rally Reactor maintenance policy
Only edit this project. Before each feature or fix, add a regression test and observe failure; implement, run Vitest and single-worker Playwright suites, inspect gameplay, and review the diff for security and correctness. Commit meaningful tested changes with repository-local Nathan Burns identity. Never force push. Push main, read back the exact remote SHA and author association, watch CI for that SHA, then verify Pages and required public assets. Do not claim delivery from local tests alone. Never commit secrets or node_modules. Preserve the one-context continuous music transport and no-SFX policy.
